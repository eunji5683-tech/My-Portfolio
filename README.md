# My Portfolio

바이브코딩으로 만든 작은 프로젝트들을 한 곳에 모아 보여주는 포트폴리오 메인 페이지입니다.

## 포함된 프로젝트

- **환율 변환기** — 달러와 원화를 빠르게 계산해주는 웹 도구
- **스네이크 게임** — 키보드로 조작하는 클래식 뱀 게임
- **홍보자동화** — 매장 사진 보정과 홍보 문구 생성을 자동화한 파이썬 도구

## 파일 구성

- `index.html` — 포트폴리오 메인 페이지 구조
- `style.css` — 파스텔톤 + memphis 스타일 디자인
- `main.js` — 카드 클릭 시 각 프로젝트로 이동하는 기능

## 사용 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.
